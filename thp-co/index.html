›
NAM Applianceรับ SSO / Reverse Proxy / Portal ตามโดเมนที่กำหนด
App / SSO
ใช้ HTTPS 443 สำหรับ app, login, portal, SAML และ OIDC
Admin Console
ใช้ HTTPS 8443 และจำกัดเฉพาะ Admin network โดย target เฉพาะ IP 10.239.200.21, 10.239.200.22 และ 10.239.200.31
Cookie Domain
ฝั่งระบบใหม่ใช้ .thailandpost.co.th ไม่แชร์ cookie ข้าม root domain กับ .com

›

thailandpost.co.thNAM Appliance รองรับบริการเป้าหมายหลัง migration
ประเด็นที่ต้องตรวจสอบก่อน implementation: ค่า SAML metadata, Entity ID, certificate, NameID, attribute mapping, logout URL และ timeout ต้องยืนยันจาก configuration จริง

6. Implementation Plan

ลำดับงานที่เสนอสำหรับการเตรียมระบบ ทดสอบ transition และดำเนินการ cutover ไปยัง thailandpost.co.th

Phase งานหลัก ผลลัพธ์ที่ต้องได้ สิ่งที่ต้องตรวจ
Phase 0
เตรียมข้อมูล		 ยืนยัน DNS, LB Listener, VIP, Port Mapping, certificate และ firewall route รายการค่าที่ THP ยืนยันพร้อมนำไปตั้งค่า DNS, route, certificate, health check, admin access
Phase 1
ตั้งระบบใหม่		 ตั้งค่า NAM Appliance IP 10.239.200.21, 10.239.200.22, 10.239.200.31 และ 10.239.200.32 แล้วกำหนด service สำหรับ thailandpost.co.th ระบบใหม่พร้อมรับ UAT 443, 8443, node health, cookie domain, admin console เฉพาะ IP 10.239.200.21, 10.239.200.22 และ 10.239.200.31
Phase 2
เชื่อม SSO		 ตั้ง federation / SAML ระหว่างระบบเดิมและระบบใหม่ตาม configuration จริง ผู้ใช้สามารถใช้งาน flow SSO ระหว่างโดเมนได้ตามแผน migration SAML metadata, NameID, attribute, certificate, logout, timeout
Phase 3
Cutover		 ย้ายบริการไป thailandpost.co.th และทยอย retire หรือ redirect บริการ thailandpost.com บริการหลักใช้งานผ่านโดเมนใหม่ redirect loop, bookmark, monitoring, audit, user support

7. ข้อมูลที่ต้องยืนยันร่วมกับ THP

รายการข้อมูลด้าน network, DNS, security และ SSO configuration ที่ต้องยืนยันก่อนเริ่ม implementation

Network / DNS / LB

  • DNS name ที่จะใช้งานจริง เช่น app, portal, sso และ admin
  • VIP / Listener สำหรับ thailandpost.co.th
  • กรณีใช้ VIP เดียวหลาย hostname ต้องยืนยัน SNI / HTTP Host / LB policy
  • Port Mapping สำหรับ 443, 8443 และ management port ที่จำเป็น
  • Firewall route ระหว่าง user, LB, NAM, AA, SSPR และ user source

NAM / SSO Configuration

  • Cookie Domain ของระบบใหม่: .thailandpost.co.th
  • Admin Console target เฉพาะ 10.239.200.21, 10.239.200.22, 10.239.200.31
  • SAML / OIDC endpoint และ certificate ที่ใช้จริง
  • AA / MFA และ SSPR flow ที่จะใช้ระหว่าง migration
  • แผน retire หรือ redirect สำหรับบริการ thailandpost.com
Prepared for THP SSO / NAM domain migration discussion. Final DNS, VIP, listener, firewall and SSO configuration values require joint confirmation before implementation.
